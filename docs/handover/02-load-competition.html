Loading a Competition from GliderScore

GliderScore stays the scoring authority. You build the competition there as you always have; the base station imports it so the timers and the audio know what is being flown, and hands the flight times back at the end of the day.
02
Sheet

Before you start

  • GliderScore 6 on a Windows PC, with the competition already fully built: pilots entered, rounds created, a task set on every round, and the group draw done.
  • It must be an F3K or F5K competition — the import list hides everything else.
  • A way to move one file across — join the PC to F3K_OPS, or carry it by USB stick to whatever you are browsing from.
  • The base station powered up and the web UI open (Sheet 01).

Import it GliderScore → Import

  1. Find the GliderScore database. It is GliderScoreData.mdb, normally in C:\GliderScore6\. Close GliderScore so the file is not mid‑write, then take a copy — the base station never touches your original.
  2. Upload it. Open GliderScore → Import, choose the .mdb under Step 1 and press Upload. It is a big file; give it a few seconds. The copy stays on the Pi until you upload another, which replaces it.
  1. Pick the competition. Step 2 lists every F3K and F5K competition in that database with its date, venue, pilot count and how many rounds have tasks set. Check those match, then press Import on the right row.
  2. You land on Comp Setup. The competition is now on the base station. Nothing has reached the timers yet — that happens when you load a heat on Run.

What comes across

PilotsNames and the competition entry list
RoundsRound number, task letter, working time
Group drawWhich pilot flies in which heat, per round
DisciplinePer round — a mixed comp stays mixed

Scores, penalties and drops are not imported. The base station records flight times; GliderScore does the scoring.

Check it landed

  • Comp Setup — listed, with the right pilot count
  • Rounds — every round shows its task letter, name and working time
  • Rounds — heats list real names, not TBD
  • The round count matches GliderScore

A TBD slot is a deliberate placeholder for a heat one pilot short. TBD everywhere means the draw was never done in GliderScore.

The structure is locked after import and that is the point

Rounds, tasks and the draw come from GliderScore, so the base station will not let you edit them — Rounds shows “Structure locked” and the Draw, Add Round and Edit controls are gone. Two copies of the draw that disagree is exactly the failure this prevents. Change it in GliderScore and re‑import. Re‑importing the same competition is refused, so to take a changed draw you must first delete it from Comp Setup — which also deletes any flights already recorded against it. Do that before the day starts, not during.

Load the audio pack optional — but it is what reads the pilots' names out

GliderScore builds a folder of .wav files per competition — one per pilot name, plus round, group and task announcements — in C:\GliderScore6\Audio. The base station owns the speaker, so they have to be here.

  1. Zip the Audio folder on the GliderScore PC.
  2. Upload the zip on the same GliderScore → Import page. It reports how many files were added, updated and already current.
Pilot name files are regenerated per competition A base station that was current last weekend has no recording for any pilot who has joined since. Re‑upload the whole folder each event — only new and changed files get written, so it is cheap, and it is the intended way to use it.

Without the pack the competition still runs perfectly; the call‑up simply has no name to speak. Round and task cues are unaffected.

Or build one by hand no GliderScore needed — good for a club day or a quick test

  1. Comp Setup → New Competition. Name it, choose the discipline (F3K, F5K or mixed).
  2. Add pilots from the Pilot Registry, or add new names — there is a bulk paste‑in import too.
  3. Rounds → + Add Round. Choose the task; the working time comes with it. Repeat per round.
  1. Press Draw on each round. Round 1 is random; later rounds use FAI reverse‑standings snake seeding off the live results. Or build heats by hand with + Group.
  2. If you will export to GliderScore set the matching GliderScore CompNo on Comp Setup now, so the export lines up with the right competition.
Worth knowing before the day A hand‑built competition is not locked — you can add rounds and redraw as you go, which is what makes it good for a club day.  ·  For an imported competition the Leaderboard is labelled unofficial: it is there so the CD can watch live standings, but GliderScore owns the drops, the normalisation and the result the pilots are given.  ·  F5K motor‑cut altitudes are entered on the watch during the round, not imported.
