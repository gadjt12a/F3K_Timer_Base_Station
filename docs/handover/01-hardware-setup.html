Hardware Setup & First Power-On

Everything in this kit is already built, flashed and configured. Nothing to image, install or flash — plug it together, power it up, connect a phone, and it runs.

What is in the kit WiFi passwords and the SSH login are on the card supplied with the kit

ItemWhat it isNotes
Raspberry Pi 4 base stationRuns the whole system USB‑C power supply. The MT7612U USB WiFi adapter is already fitted — leave it in.
ESP32‑S3 timer watchThe caller's stopwatch Waveshare 1.75" round AMOLED. Internal battery, charges over USB‑C.
Bluetooth speakerField audio — calls and cues UE WONDERBOOM, already paired to the Pi.
Your own phone or laptopThe CD's console Any modern browser. Nothing to install.

Power on, in this order

  1. Speaker first. Power the WONDERBOOM on and wait for its ready tone. The Pi reconnects to a speaker that is already awake; one woken later needs a nudge from Settings.
  2. Pi next. Plug in the USB‑C supply and allow 45–60 s to boot and raise both WiFi networks.
  3. Watch last. Short press the top‑left button (L). It finds the timer network by itself.
Never hold the top-right button at power-on Holding R at boot forces ESP32 download mode and the screen stays blank. Power cycle it without touching any button.

Connect your console

Over WiFi
in the field		 Join F3K_OPS, then open http://192.168.20.1:8080. Any address you type is redirected there, so go in the bar is enough.
Over ethernet
on a desk		 Patch the Pi into your router and open http://f3kbase.local:8080. Needed only for software updates — it is the Pi's one route to the internet.

You should land on a dark page headed GLIDE BASE, with the tabs Comp Setup · Rounds · Run · Results · Leaderboard · GliderScore · Settings.

The three networks kept separate on purpose — the timer network carries no internet traffic

F3K_BASEwlan1 — USB adapter192.168.10.1 Timer watches only. Do not join this with a phone.
F3K_OPSwlan0 — onboard192.168.20.1 CD, scorer and spectator phones or tablets.
eth0wiredDHCP — f3kbase.local Optional. Internet for software updates only.

Set the audio up

In Settings → Audio Output, pick one and press Test:

BluetoothClick the paired WONDERBOOM to connect. The competition setup.
3.5 mm StereoA powered speaker in the Pi's jack. Works with no setup at all.
USB AudioOnly selectable with a USB sound device plugged in.

Lead fires every cue a set number of seconds early to cancel Bluetooth's playback delay, and is tuned for this speaker. On the 3.5 mm jack set it back to 0 — and only tune it against the speaker you will compete with.

Confirm it is all up

  • Web UI loads, nav bar present
  • Settings → Connected Timers lists the watch with a firmware version
  • The watch shows T1 and green BASE OK
  • Settings → Audio shows the speaker connected; Test is audible
  • Battery percentage showing on the watch

Grey BASE… means still associating — give it 20 s. Grey that never clears means the USB adapter did not come up; reboot with it plugged in.

The watch's two buttons stopwatch orientation — both buttons at 12 o'clock

ButtonPositionWhat it does
L — power keytop‑left Secondary: scratch, step a setting, page the log, open Round Recall.
R — BOOTtop‑right Primary: start and stop the flight, confirm, navigate. Hold to confirm.

Holding L is a hardware power‑off the firmware never sees, so a long press always means R.

Two things that look like faults

  • The screen goes black. AMOLED burn‑in protection — it blanks after two minutes idle and any button wakes it. A live round never blanks.
  • Start buttons dead at idle. Correct: the base owns round starts while the watch is connected. They unlock in the last two seconds of prep.

Reference

If something is wrong

Web UI will not load Check you are on F3K_OPS, not home WiFi
A WiFi network missing systemctl status hostapd; reseat the adapter
Watch will not connect Power cycle the watch; the base needs nothing
No audio Wake the speaker, re‑click it in Settings, check volume

Admin & shutdown

SSH hostpi@f3kbase.local — login on the card
Health checkcurl http://localhost:8080/health
Logsjournalctl -u f3k-server -n 50
Shut downsudo poweroff, then wait for the green LED to stop

Pulling power will not lose flights — they are written as they are flown — but copy the results from Settings → Data Backup first.

Please leave these alone — this is a working dev rig on loan Do not re‑flash the watch, reset the Pi's network config, run anything under setup/, or press Settings → Update from GitHub. Everything an evaluation needs is in the web UI; nothing requires SSH.
