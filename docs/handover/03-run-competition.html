Once, before the first heat

  • Settings → Audio — output chosen, volume set, Test audible from where the pilots stand
  • Settings → Audio → Call‑up — default on or off for the day
  • Settings → Connected Timers — all present, all on the same firmware
  • Watches numbered (Renumber), charged, handed to the right callers
  • Rounds — the round 1 draw reads correctly

The protocol is versioned, so a mixed fleet is a mixed protocol. The base updates stale watches by itself — but only while no heat is loaded.

  1. Click the next heat in the queue. It goes Loaded and the pilot list reaches the watches at once — before prep, so there is time to choose.
  2. Each caller picks their pilot on the watch. L / R to scroll, hold R to confirm — the name then replaces BASE OK.
  3. Press START. The base now runs everything — call‑up, prep countdown and beeps, the long tone at window open, the time calls, the landing window. A watch with no pilot picked raises a yellow panel, but nothing stops you starting.
  4. Flight times arrive by themselves as each flight is stopped, into the log on the right. Back at IDLE, mark the heat ✓ Done and load the next; completed heats sink to the bottom of the queue.

The buttons on the Run screen

START Begins the sequence. Needs a loaded heat.
ABORT Stops the round dead, heat stays loaded — so you can re‑run it.
✕ Clear Puts the heat down without running it.
🔊 Call-up On or off for this heat only; an amber dot means it is overriding the Settings default.
Skip to 1:00 During prep, when everyone is already on the line.
✓ Done Marks the heat complete. ↩ Undo reverses it.

The watch, during a round

R click Start / stop the flight — the one button that matters. The screen reads FLYING (3): the launch number, which is what a launch‑limited task needs.
L click Scratch the flight just recorded (confirm with R). On a Poker round it declares the next call instead.
At time up The results screen ranks the best times by colour. L pages a long log, and opens Round Recall — the watch's own record of the last three rounds.

Start buttons are locked while the watch is connected — the base owns round starts — and unlock in the last two seconds of prep. A launch before the window opens is flagged red, scores zero, and still consumes a launch.

F5K — altitude entry

After time up the watch asks for each flight's motor‑cut altitude in turn:

R click+1 m — ones digit, rolls 9 → 0
L click+10 m — tens digit, rolls 100 → 0
hold RConfirm, move to the next flight

Target tasks — Poker and Ladder

The base tells the watch which task and how to fly it. The flight clock counts down to the target — that is what the timekeeper calls to the pilot — and landing flashes ACHIEVED or MISSED. Only an achieved call scores, so the time‑up list shows the call beside the flown time.

When something needs fixing, and how the day ends

Fixing things

Wrong time recorded Results → delete it, add it back correctly
Heat must be re‑flown ABORT, delete that heat's flights on Results, START again
Watch drops out It times on alone and re‑sends on reconnect; nothing is lost
Wrong heat loaded ✕ Clear, load the right one; swapping mid‑round is refused

CSV fallback: GliderScore → Export also offers a CSV. After importing it, check the pilots matched — it carries the base station's own pilot IDs, not GliderScore's numbers.

Results back to GliderScore

  1. On GliderScore → Export, download F3KSync.exe onto the CD's PC.
  2. Run it, point it at the GliderScore folder, enter the base station's URL, press Connect.
  3. Choose the competition and press Sync Scores.
Always finish in GliderScore The base records flight times; drops, normalisation and penalties belong to GliderScore, so the day's last action is Recalculate there. Copy the results from Settings → Data Backup first.
